# AI 2D→3D Shoe Multi-Part Segmentation & True Color Customization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform AI 2D→3D generated shoes from single-mesh/charm-only models into 8-part customizable 3D shoes with true, vibrant color replacement (no dark/muddy overlay), matching the behavior and quality of CAD GLB shoes.

**Architecture:** A post-processing Python tool (`tools/segment-shoe-glb.py`) partitions raw AI continuous meshes into 8 standard KickCraft primitives and materials (`UpperMaterial`, `MidsoleMaterial`, `OutsoleMaterial`, etc.) and delights textures into neutral shading maps. The PHP backend is updated to persist `mesh_map` and `part_colors` for AI products, and the Vue 3 frontend (`customization.js`, `MeshTagger.vue`, `ProductCustomizer.vue`, `MarketplaceOrderModal.vue`) is updated to unlock full 8-part customization for AI shoes.

**Tech Stack:** Python 3 (struct, json, PIL), Vue 3, Google `<model-viewer>`, PHP 8 / MySQL, Node.js test runner.

**Spec:** `docs/superpowers/specs/2026-10-12-ai-shoe-multipart-recoloring-design.md`

## Global Constraints
- Zero physical SQL `DELETE FROM` statements; preserve soft-delete conventions.
- Maintain full compatibility with existing 597 automated tests with zero regressions.
- Preserve KickCraft brutalist aesthetic tokens (`border-2 border-stone-900`, `shadow-[4px_4px_0px_#202220]`, terracotta `#b94d27` accents).
- Pure local offline execution: segmentation and color customization must work without external cloud dependencies.
- Fast performance: segmentation and model processing must complete in $< 1.5$ seconds per GLB.

- [ ] **Step 2: Run the test to verify it fails**

Run: `node --test test/ai-segment-glb.test.js`

- [ ] **Step 3: Implement `tools/segment-shoe-glb.py`**

Implement:
1. GLB parser reading JSON chunk and binary buffer.
2. Bounding box computation from `POSITION` accessor.
3. Coordinate normalization ($Y$ height: $0$ sole to $1$ top collar, $Z$ length: $0$ heel to $1$ toe, $X$ width: $-0.5$ to $+0.5$).
4. Triangle index classifier assigning each triangle to `Outsole`, `Midsole`, `ToeCap`, `Laces`, `Tongue`, `HeelPanel`, `SideAccents`, or `Upper`.
5. Primitives splitter creating separate index buffer views and assigning corresponding material indices.
6. Texture delighter: Desaturating and normalizing the base color texture into a high-fidelity neutral grayscale shading/ambient-occlusion map.
7. Packing back into compliant binary GLB.
